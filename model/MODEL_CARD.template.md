This model writes programs in **Ken**, an experimental programming language designed to be written by small AI
models. It was trained on tasks over tables of data: you describe a table and give a task in plain English, and it
answers with a short Ken program. It answers directly, without a reasoning phase.

It is a LoRA adapter (rank {{LORA_RANK}}) for [Gemma 4 12B](https://huggingface.co/unsloth/gemma-4-12b-it), not a full
model: load it on top of the base model.

## What is Ken?

Ken is an experiment: a language made so that small models can write it reliably. Version 0.1 is a postfix
pipeline language: a program is a chain of steps, and Ken translates the chain to Python and runs it. This program
finds the five best-selling products among completed orders:

```
csv orders.csv where status eq done by product [ each qty sum ] top 5 map [ fmt "{0}: {1}" ] print
```

Read left to right: load the orders, keep the completed ones, add up `qty` per product, keep the top five, print them.
More about the language is in the source repository{{REPO_LINK}}.

## How to use it

You need the `kenlang` Python package. It builds the exact prompt this model was trained on and runs the program the
model writes.

```python
from unsloth import FastModel
from kenlang.llm import build_prompt, extract_code

model, processor = FastModel.from_pretrained("{{REPO_ID}}", max_seq_length=4096, load_in_4bit=True)
FastModel.for_inference(model)
tok = getattr(processor, "tokenizer", processor)

data = "The file `orders.csv` has columns date, customer, product, category, qty, price, status."
task = "Write a Ken program that prints the number of orders with status `done`."
prompt = tok.apply_chat_template(
    [{"role": "user", "content": build_prompt(task, data)}],
    tokenize=False, add_generation_prompt=True, enable_thinking=False)
inputs = tok(prompt, return_tensors="pt", add_special_tokens=False).to(model.device)
out = model.generate(**inputs, max_new_tokens=400, do_sample=True, temperature=0.6, top_p=0.95, top_k=64)
program = extract_code(tok.decode(out[0, inputs["input_ids"].shape[1]:], skip_special_tokens=True))
print(program)
```

The `kenlang` package lives in the source repository{{REPO_LINK}} and is not on PyPI yet. For now, install it from a
copy of the repository with `pip install -e .`. With the package installed, `kenlang run program.ken` runs the
result. The file `kenlang_reference.md` in this repository is the exact text of the language description in the prompt.
Describe your table the way the training examples do: the file name and, for each column, its name and meaning.

**Be careful with what the model writes.** A Ken program can do anything a Python program can, including deleting
files. Run programs written by an AI only in a safe, isolated place (see `SECURITY.md` in the source repository).

## Limits

- **Small tests.** The hand-written set has seven questions, so one question moves its headline number by about
  {{ONE_TASK}} percentage points.
- **Tables like the ones it saw.** Training used three tables of one general kind (rows with a date, a few categories,
  a quantity, a price and a state). The unseen-table set checks a different shape, but a very different table, for
  example one with several files to join, is untested.
- **It needs its exact instructions.** It learned from one specific language description. If you change that text,
  or use a different version of the language, expect worse results.
- **It is not a safe code generator.** What it writes is real, runnable code. Check it before you run it.
